# DesktopGo

一个用 Go 语言编写的 **Windows 桌面增强管理工具**。

## 功能

- 通过**分组卡片**管理桌面图标，支持新建、删除、缩放、改色
- **桌面模式**：窗口嵌入 Windows 桌面层，替代原生桌面
- **窗口模式**：独立窗口浏览和管理分组
- 系统托盘常驻，后台运行不干扰
- 监听桌面目录文件变更，自动同步
- 支持外部文件拖放、右键菜单（打开、重命名、删除等）
- 自动读取并显示当前 Windows 壁纸

## 运行

```cmd
# 桌面模式（替代系统桌面）
desktop_go.exe
desktop_go.exe -d

# 窗口模式（独立窗口）
desktop_go.exe -w
```

## 构建

需要 Go 1.24+ 和 MinGW-w64，执行 `build.bat` 即可。
